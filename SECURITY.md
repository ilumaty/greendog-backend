# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅        |

## Reporting a Vulnerability

Ce projet est développé dans un cadre académique (SAE Institute Geneva).  
Pour signaler une vulnérabilité, ouvre une issue sur ce dépôt ou contacte-moi directement via GitHub.

Les rapports seront traités dans un délai de 7 jours.
